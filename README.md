# Kathiyawad Ice Cream

A modern, responsive web application for Kathiyawad Ice Cream crafted with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Interactive Menu & Flavours**: Explore signature flavours like Kesar Pista, Alphonso Mango, Rajbhog Royale, and Mawa Badam.
- **Custom Ice Cream Builder**: Build custom scoops with various toppings and flavours.
- **Smooth Animations**: Powered by Framer Motion and Lenis smooth scrolling.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

## Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm / npm

### Installation

```bash
# Install dependencies
pnpm install
# or
npm install
```

### Development

```bash
pnpm dev
# or
npm run dev
```

### Build for Production

```bash
pnpm build
# or
npm run build
```
